# 桌面前端视觉轻量化 · 第一版设计（v1）

状态：提案（待评审） · 范围：`desktop/frontend`（styles.css + 组件级微调） · 日期：2026-09-18

## 0. 背景

结构层的减法已经做完：壁纸主题包已删（#484）、右侧 dock 换成悬浮胶囊（#485）、侧栏 Codex 化且项目/会话平权（#486 + #487 跟进）。但**视觉层还留着旧时代的重量**：多层阴影、大量边框、失控的字号/圆角碎片。本设计给出第一版收敛方案——目标不是换风格，而是把"重"的部分系统性减掉。

## 1. 现状审计（styles.css，35,390 行）

| 指标 | 数值 | 问题 |
|---|---|---|
| box-shadow 声明 | 305 处 | 同一 tokens 名（--shadow-1/2）在 6 个主题变体下值各不相同，无统一阶梯 |
| 线性/径向渐变 | 117 处 | 主题库预览占大头（合理）；业务组件散落约 20 处（.layout、.reasoning、.tool、.turn-collapse、context-ring 气泡等），属噪音 |
| backdrop-filter | 28 处 | GPU 合成开销，webview 内尤甚 |
| transition/animation/@keyframes | 312 处 | 无统一时长/曲线 tokens |
| border 声明行 | 1,770 处 | 盒子套盒子（panel 内 card 内 row 各自带边框） |
| border-radius 取值 | 15+ 种（3/4/5/6/7/8/9/10/12/999px/50%…） | 无圆角阶梯 |
| 硬编码 font-size | 约 660 处 px 直写（11px×119、12px×103、13px×66、11.5px×47…） | 绕开 --text-* token，字号缩放（--font-scale）对这些不生效 |
| :root 块 | 1,280 个 | 6 个 data-theme-style × 全量 token 覆写，改一个基础 token 要动 7 处 |
| 文件形态 | 单文件 35k 行，含压缩段落与格式不一致 | 维护性差，css check 已多次被尾部重复规则坑过 |

**结论**：重的根源不是某个组件，而是 token 层无纪律 + 每个组件各自为政。轻量化必须从 token 收敛开始，而不是逐个组件手调。

## 2. 设计原则（按优先级）

1. **面优于线**：用表面明度差区分层级，能不加边框就不加；加了边框就不加阴影（二选一）。
2. **一层阴影封顶**：浮层（菜单/对话框/胶囊）最多一层柔和投影；文档流内元素禁止投影。
3. **留白优于分隔线**：区块之间用间距（≥12px）呼吸，不画 hairline。
4. **节奏锁死**：字号、圆角、间距只允许从阶梯里取值；例外必须在 token 层加，不许组件里写魔法数。
5. **动效降噪**：只保留状态反馈类动效（hover/press/展开），装饰类（漂移、脉冲、渐变扫过）全部移除。

## 3. Token 第一版

### 3.1 表面（暗色基准，亮色主题同比例）

现有 5 级表面（--bg #090a0c → --bg-elev-2 #222631）明度差过大，导致每层都要描边才看得清层级。收敛为 3 级 + 更平的阶差：

| token | 现值 | v1 | 说明 |
|---|---|---|---|
| --bg | #090a0c | #0d0f12 | 底抬亮一点，减少"深坑"感 |
| --bg-soft | #111319 | #14171c | 与底差 ΔL 缩小约 1/3 |
| --bg-elev | #191b22 | #1a1e24 | 卡片/输入框 |
| --bg-elev-2 | #222631 | #20242c | 仅浮层可用，文档流禁用 |
| --border | #343945 | #2a2f3a | 描边整体减淡 |
| --border-soft | #252a34 | #212631 | 与 soft 表面几乎融合 → 促使"少描边" |

### 3.2 圆角阶梯（4 档）

`--r-xs: 4px`（复选框/徽标） · `--r-sm: 6px`（输入框/小按钮/行） · `--r-md: 10px`（卡片/面板） · `--r-lg: 14px`（对话框/浮层） · `--r-full: 999px`（胶囊/圆点）。
现有 3/5/7/8/9/11/12px 全部就近归档（8px→10px 或 6px 按视觉尺寸判断）。

### 3.3 阴影（2 档，单层）

- `--shadow-overlay: 0 8px 24px rgba(0,0,0,0.28)` — 菜单/对话框/悬浮胶囊，唯一允许的投影。
- `--shadow-focus: 0 0 0 2px color-mix(in srgb, var(--accent) 30%, transparent)` — 键盘焦点环（统一现在 1px/2px/24%/16% 各写各的 focus ring）。
- 其余 300 处 box-shadow：文档流内全部删除，改边框或表面差；主题变体里的 --shadow-1/2 覆写全部删除（token 层只定义一次）。

### 3.4 字号（锁死 token）

660 处硬编码 px 全部归档到现有 --text-2xs~xl（10–18px）：10/10.5/11/11.5px → --text-xs(11px)；12/12.5px → --text-sm(12px)；13px → --text-md(13px)；14/15px → --text-base/--text-lg。**附带收益**：这些位置从此响应 --font-scale。

### 3.5 间距（4px 网格）

新增 --s-1: 4px / --s-2: 8px / --s-3: 12px / --s-4: 16px / --s-6: 24px；不强制一次性替换全部 padding，仅新增/改动代码必须取值于网格。

## 4. 分组件规范（第一版）

| 组件 | 现状 | v1 |
|---|---|---|
| 侧栏 | 三段（主操作/项目/会话）+ 底部，行 hover 用背景 | 保持；区块间去掉一切分隔线，用 8px 间距；行 hover 统一 --sidebar-hover，active 用 accent 13% 底（现状保留） |
| 对话消息流 | 消息卡片多层边框+圆角混杂 | 消息去掉卡片边框，仅 user/assistant 用表面差 + --r-md；meta 行字号降半档 |
| 输入区（Composer） | 外框粗、内嵌按钮各自描边 | 外框单层 --border-soft + --r-md；内部按钮去边框，仅 hover 背景 |
| 按钮 | primary 已是纯色 accent（各主题 --control-primary-bg 各自定义） | 保持纯色无投影；hover 用亮度偏移不加边框；focus ring 统一 --shadow-focus |
| 悬浮胶囊（WorkspaceFloat） | 双层阴影+backdrop-filter | 单层 --shadow-overlay；backdrop-filter 仅在内容真正重叠时保留 |
| 状态栏/底栏 | 多层描边 | 纯 --bg-soft，顶边一条 --border-soft |
| 滚动条 | 10px | 8px；thumb 透明度降 10% |
| 空状态 | 图标+文案各自实现 | 统一 --fg-faint、--text-sm，图标 16px，不描边 |

## 5. 动效

- 时长 tokens：`--dur-fast: 120ms`（hover/press）、`--dur-med: 200ms`（展开/浮层进出）；曲线统一 `cubic-bezier(0.2, 0, 0, 1)`。
- 移除：装饰性 keyframes（呼吸/漂移/渐变扫过）、>300ms 的过渡、同一元素 ≥3 个属性的联动 transition。
- 312 处动效目标减到 ~150 处以内；backdrop-filter 28 → ≤10。

## 6. 实施计划

| 阶段 | 内容 | 交付 |
|---|---|---|
| P1 token 收敛 | 3.1–3.5 的 token 定义与主题变体去重；硬编码字号/圆角脚本化归档（正则映射表人工复核） | 1 个 PR，纯 token + 机械替换，视觉差异可控 |
| P2 组件减重 | 第 4 节逐组件：删投影/边框/渐变（每类一 commit） | 1–2 个 PR |
| P3 动效与文件治理 | 第 5 节；styles.css 按 domain 拆分（base/tokens/components/*），消除压缩段落与尾部重复规则 | 1 个 PR，纯搬运零视觉 diff |

**风险与对策**：① 6 个主题变体联动——P1 必须带脚本比对每个 data-theme-style 下 token 表 diff；② 无视觉快照——P1/P2 每步在浅色（slate）+ 深色（默认）下人工过一遍核心五屏（侧栏/对话/输入/设置/主题库）；③ 机械替换误伤——字号/圆角映射表放 `scripts/` 供复查。

## 7. 验收标准

- box-shadow ≤ 60、backdrop-filter ≤ 10、border-radius 取值 = 阶梯 5 种、硬编码 font-size = 0（除 token 定义处）
- 主题变体仅覆写色板（表面/文字/accent/语义色），不覆写阴影/圆角/动效 token
- 六屏人工走查无层级识别障碍；--font-scale 缩放对全部正文生效
